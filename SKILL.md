# Nature Humanization

## Overview

Nature Humanization is a writing-refinement skill for revising existing text so that it reads more naturally, directly, and professionally while preserving the author's substantive content.

The skill has two modes:

- Academic mode for academic, research, analytical, and coursework writing.
- General mode for other forms of prose that require naturalization and stylistic refinement.

Always select the appropriate mode before editing.

## Mode Selection

### Academic Mode

Use Academic Mode when the text is an:

- academic paper
- journal manuscript
- coursework assignment
- research report
- literature review
- empirical analysis
- policy analysis
- business analysis
- methodology section
- results section
- Discussion section
- Conclusion section
- academic Markdown, Word, or LaTeX document

Before editing, read and follow:

`Nature_Humanization_Academic.md`

Treat that file as the primary editing rules for Academic Mode.

### General Mode

Use General Mode when the user wants ordinary prose revised for naturalness, clarity, precision, or reduced formulaic language and the text does not require the full academic framework.

Before editing, read and follow:

`Nature_Humanization_General.md`

Treat that file as the primary editing rules for General Mode.

## Priority Rules

When the text is clearly academic, research-oriented, evidence-based, analytical, or intended for formal assessment or publication, use Academic Mode.

When the text is non-academic, use General Mode.

If the boundary is unclear, prefer Academic Mode when preserving technical precision, evidence, citations, data, or formal argumentation is important.

## Source Preservation

Do not invent facts, evidence, references, statistics, quotations, findings, methods, or claims.

Preserve substantive meaning unless the user explicitly asks for substantive rewriting.

When editing academic material, preserve:

- numerical values
- statistical results
- citations
- references
- variable names
- model specifications
- factual claims
- technical terminology where necessary

If a technical expression cannot be safely rewritten without changing its meaning, retain it.

## Output Behavior

When the user asks for direct revision, provide the revised text rather than only describing possible improvements.

Do not explain every individual edit unless the user requests an explanation.

Preserve the user's requested output format whenever possible.
